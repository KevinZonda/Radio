## Windows 1.0（1985）

**[史实]** Windows 1.0 在 MS-DOS 上提供简单图形界面、有限多任务和 tiled windows；Computer History Museum 指出它初期并未广泛普及。
https://www.computerhistory.org/revolution/personal-computers/17/305/1208

**[解释]** 它更像“图形化地操作 DOS/programs”，而不是 Macintosh 那种完整的 object-centered world。MS-DOS Executive 暴露 `.EXE` 等机器/程序结构。

## Windows 2.x

窗口开始可以 overlap；GUI grammar 逐渐稳定：active window、focus、minimize/maximize、menu/dialog/control。

## Windows 3.x

Program Manager 与 File Manager 分离是非常重要的 HCI 证据：

- Program Manager：我有哪些程序？
- File Manager：我的文件在哪里？

**[解释]** 用户必须同时内化 program ontology 与 file ontology。这种区分今天看似自然，其实是几十年计算文化教育的产物。

## 平台标准化

到了 1990s 初期，界面的关键问题已经不仅是“能不能图形化”，而是不同 app 是否能共享 menus、dialogs、buttons、shortcuts、clipboard 等 conventions。

**[解释]** HCI 从单个产品的 usability，扩展为整个生态的“语法标准化工程”。
