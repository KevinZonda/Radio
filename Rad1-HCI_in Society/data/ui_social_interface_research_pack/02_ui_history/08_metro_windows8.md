## 官方原则

Microsoft 2011–12 的文档把 Metro 概括为：clean/light/open/fast、celebrate typography、alive in motion、content not chrome、authentically digital。并明确反对为了传统而模拟 analog controls。
来源：https://learn.microsoft.com/en-us/archive/msdn-magazine/2012/january/windows-phone-design-your-windows-phone-apps-to-sell

BUILD 2011 也强调用 color、typography、motion 构成 Metro 体验。
https://learn.microsoft.com/en-us/shows/build-build2011/app-395t

## 理论意义

**[解释]** Metro 是 GUI 史上最明确的一次“数字不必伪装成物理世界”的宣言之一。它假设：

- 用户已经理解 touch 和 navigation conventions；
- typography 本身可以是 UI；
- content 可直接成为交互对象；
- chrome 可以最小化甚至隐藏。

## 但 Windows 8 也提供反证

当 hidden gestures / edge commands / dual environments 与用户既有 PC convention 不一致时，discoverability 出现明显问题。

**[限制]** “教育完成”不是全社会、全设备、全 modality 一次性完成。某个 convention 是否能撤掉提示，必须看目标用户是否真的已经内化它。
