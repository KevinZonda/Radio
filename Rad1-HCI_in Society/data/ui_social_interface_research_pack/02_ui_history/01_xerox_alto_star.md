## Alto

Computer History Museum 对 Alto 的概括很适合本项目：mouse、visual UI、WYSIWYG、networking 等被组合到一起，使非专业用户可以更专注任务，而不是学习机器技术细节。
来源：https://www.computerhistory.org/revolution/input-output/14/347

## Star（1981）

**[史实]** Star 以 physical office metaphor 组织工作：documents、folders、file drawers、in/out baskets、printers。设计原则包括 familiar user conceptual model、seeing and pointing、WYSIWYG、universal commands、consistency、simplicity 等。

**[解释]** Star 最重要的发明不是“图标长得像文件夹”，而是改变用户面对计算机时的本体：从 program/process/path 转向 document/folder/printer/task。

### 认知转换

```text
machine ontology: program / process / storage / device
user ontology:    document / folder / printer / mail basket
```

### 为什么这像“教学层”

用户不需要先理解内部文件系统，就能通过现实办公室的结构开始操作。这正是 interface metaphor 的脚手架功能。
