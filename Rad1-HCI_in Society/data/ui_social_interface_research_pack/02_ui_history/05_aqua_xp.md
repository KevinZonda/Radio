## Mac OS X Aqua（2000）

Apple 发布 Mac OS X 时强调全新的 Aqua UI、Dock、新 Finder、半透明元素与 fluid animation，并称目标是让 computing 更容易，同时服务消费者和专业用户。
来源：https://www.apple.com/newsroom/2000/01/05Apple-Unveils-Mac-OS-X/

**[解释]** Aqua 的动画、透明和 Dock 不再主要是在解释“什么叫窗口”，而是在建立一种数字空间的连续性：对象有位置、层级、缩放、运动和归属。

## Windows XP Luna（2001）

XP 大量使用颜色、圆角、梯度、强 affordance 与 task-oriented organization，把 PC 进一步包装成家庭消费设备。

**[解释]** XP 的视觉并不只是“儿童化”或“塑料感”。它强化：

- 什么能点；
- 当前 hover / active 状态；
- 下一步可做什么；
- 系统应更像友好的消费品，而不是办公室技术设备。

### 设计阶段变化

1995：**让系统状态可理解**。
2000–01：**让数字环境更连续、更情感化、更任务化**。
