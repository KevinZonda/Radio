## Lisa

**[史实]** 1980 年内部的 Lisa User Interface Standards 将 **simplicity** 和 **integration** 作为两大目标，并写明要建立在用户已经熟悉的概念上；一致系统比彼此分裂的程序更容易学、更强大。
来源：https://guidebookgallery.org/articles/lisauserinterfacestandards

**[解释]** Lisa 的核心不是“画真实物件”，而是让用户能够把已有社会经验迁移到新系统，并确保这种学习能在应用之间复用。

## Macintosh

Computer History Museum 将 1984 Macintosh 视为首个成功的鼠标驱动 GUI 个人电脑，MacPaint 展示 mouse 直接操作，MacWrite 展示 WYSIWYG。
https://www.computerhistory.org/timeline/1984/

### Macintosh 的关键教学结构

- WIMP：windows / icons / menus / pointing device。
- 菜单把 capability 外显，降低 recall。
- 一致 File/Edit 等菜单位置促进 transfer of learning。
- keyboard shortcut 形成从显式教学到 muscle memory 的梯度：先看菜单 → 记住命令 → 快捷键内化。

**[解释]** 1984 Mac 是“语义拟物 + 行为拟物”极强、视觉拟物有限的系统。把 skeuomorphism 等同皮革木纹，会漏掉它最重要的部分。
