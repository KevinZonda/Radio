# 把 1970s–2010s 看成一张“人类计算课程表”


> **证据标签**
> - **[史实]**：有原始资料、官方文档或学术文献直接支撑。
> - **[解释]**：基于多条史实做出的分析性归纳，不等于当事设计团队的原话。
> - **[假说]**：可检验的理论延伸，尤其用于 AI-native UI 部分。
> - **[限制]**：与主叙事相冲突、限制其外推范围、或提醒避免后见之明的证据。


### 1970s：学机器语言
“告诉计算机要执行什么命令。”

### Xerox Star / Lisa：学数字对象
“这里有 document、folder、printer、inbox。”

### Macintosh：学直接操作
“看到 → 指向 → 拖动 → 立刻反馈。”

### Windows 1–3.x：学窗口化与应用生态
“多个程序、多个窗口、文件与程序存在不同组织结构。”

### Windows 95：学 system state
“最小化不等于消失；Taskbar 让正在运行的东西持续可见；Start 是统一入口。”

### iPhone：学触屏身体语法
“tap、swipe、pinch、scroll、inertia。”

### Metro / iOS 7：撤掉部分提示
“文字可以直接是导航；按钮不一定必须有 bevel；现实材质不再必要。”

### Material / Fluent：学数字物理
“elevation、layer、motion、focus、context 成为状态编码。”

### AI：可能正在学数字主体
“conversation、avatar、voice、personality 让非人智能先以‘人’的社会模型进入生活。”

### 下一门课？
“delegation、scope、authorization、audit、provenance、revocation。”
