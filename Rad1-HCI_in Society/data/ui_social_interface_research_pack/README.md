# UI、社会接口与“去脸化”研究资料包

本资料包围绕一个核心问题整理：**界面是否不仅在呈现技术，也在训练社会去理解新的对象、角色与行动者？**

核心工作假说是：

> **拟物之于数字对象，可能类似于拟人化之于数字主体。**
> 早期 GUI 用熟悉的办公室物件、可见状态和直接操作，帮助人理解计算机；当这些交互惯例被内化后，界面可以逐渐撤去显式脚手架。AI 界面今天大量借用“人”的头像、名字、声音、第一人称和人格，也可能是在用既有社会模型解释一种新的非人行动者。


> **证据标签**
> - **[史实]**：有原始资料、官方文档或学术文献直接支撑。
> - **[解释]**：基于多条史实做出的分析性归纳，不等于当事设计团队的原话。
> - **[假说]**：可检验的理论延伸，尤其用于 AI-native UI 部分。
> - **[限制]**：与主叙事相冲突、限制其外推范围、或提醒避免后见之明的证据。

## 最重要的使用提醒

- “拟物 → 扁平 = 教育完成”**不应写成已经被证明的单因果历史**。现有研究支持“隐喻可以降低初始认知距离、帮助建立 mental model”，但 flat vs. skeuomorph 的实证结果并不总是一致。
- Windows 95 是极强的“教学型 UI”案例，因为其设计团队公开记录了对新手的 usability testing、Beginner Shell、Start Menu 和 Taskbar 的迭代。
- iOS 7 是“对象级拟物减弱、运动/层级级物理感加强”的好案例，而不是“完全去拟物”。
- Material Design 不是简单 flat design，它更像把“现实对象拟物”改造成“物理规律拟物”。
- “AI 的脸是过渡脚手架”属于**研究假说**。它能由 CASA、anthropomorphism、agentic systems、appropriate trust 等文献支撑，但目前不是学界既定结论。
