# 社会同态视觉 brief

## Money = trust abstraction
画面：两个人面对面记账/赊账 → 纸币/数字支付 token。
说明：从 interpersonal credit 到 portable symbolic token。

## Uniform = role visualization
画面：普通人群中一个清晰制服/badge。
说明：不是识别人脸，而是识别 role + institution + authority。

## Seal / certificate = remote authority
画面：本人不在场 → signed/sealed document 仍可执行。
说明：权威从身体 presence 转向可验证凭证。

## Corporation = non-bodied actor
画面：许多员工、合同、资产汇入一个“Company”节点。
说明：社会已经能把分布式人群组织成一个持续、可签约的主体。

## Traffic = protocol coordination
画面：没有信号灯的路口眼神谈判 vs 有信号灯的路口。
说明：从 face-based negotiation 到 protocol-based coordination。

## Queue = dimensionality reduction
画面：拥挤争抢 → 一条队 → 取号 A037。
说明：把复杂人际权力暂时压缩成一个 position/token。

## Elevator / telephone operator → interface
画面：人类 operator → button/dial/address。
说明：成熟系统将人类中介的工作拆成标准化 primitives。
