# 图片与视觉材料说明


> **证据标签**
> - **[史实]**：有原始资料、官方文档或学术文献直接支撑。
> - **[解释]**：基于多条史实做出的分析性归纳，不等于当事设计团队的原话。
> - **[假说]**：可检验的理论延伸，尤其用于 AI-native UI 部分。
> - **[限制]**：与主叙事相冲突、限制其外推范围、或提醒避免后见之明的证据。


这个目录有三类材料：

1. `assets/`：少量许可明确的实际图像示例。
2. `01_historical_screenshot_captions.md`：如果制作文章/展览/幻灯片，建议搜集的历史界面镜头及图注。
3. `02_visual_comparison_boards.md`：建议如何排成对照板，突出“教学层 → 内化 → 撤架”。
4. `03_social_analogy_visuals.md`：社会同态的视觉 brief。
5. `LICENSES.md`：实际打包图像的许可/来源。

**建议**：正式出版时尽量从 Apple / Microsoft / Google 官方设计文档、Computer History Museum、Wikimedia Commons 的授权页重新取得高分辨率材料，并按出版用途核对许可。
