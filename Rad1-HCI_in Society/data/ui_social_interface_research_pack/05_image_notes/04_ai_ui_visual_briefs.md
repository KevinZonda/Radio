# AI-native UI 视觉 brief

## 1. Character UI vs Institutional UI
左：头像、名字、voice waveform、typing dots。
右：role badge、principal、permission matrix、audit log。

## 2. Delegation Breadcrumb
`You → Project Lead Agent → Procurement Agent → Vendor`
每一层显示 capability 与 responsibility boundary。

## 3. Permission Surface
一个清晰矩阵：Read / Write / Send / Spend / Delete / Publish；支持即时 revoke。

## 4. Action Ledger
时间轴：Goal → Plan → Source → Tool → External action → Result → Evidence。

## 5. Uncertainty UI
不要只画“Confidence 87%”；同时显示 failure modes、missing data、cannot verify。

## 6. Memory Boundary
可视化 agent 当前能访问哪些 project、documents、people、time range；突出 boundary 而非“它记得我”。

## 7. Role handoff
当一个 agent 达到能力边界，UI 显示“Escalate to: Legal / Finance / Human supervisor”，而不是继续用人格话术掩盖边界。
