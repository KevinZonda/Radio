# 推荐视觉对照板

## Board A：语义拟物 vs 视觉拟物
左：1984 Macintosh 黑白 desktop。
右：iOS 6 Notes / Calendar。
标题：**拟物不等于纹理：一个系统可以视觉很平，却在 ontology 上高度拟物。**

## Board B：Windows 3.1 → Windows 95
左：Program Manager + File Manager。
右：Start + Taskbar + Explorer。
标题：**从多个内部模型到统一 home base 与 persistent state。**

## Board C：iOS 6 → iOS 7
左：leather/wood/paper。
右：translucency/layer/motion。
标题：**从 object realism 到 spatial/behavioral realism。**

## Board D：iOS 7 → Material
左：flat/borderless controls。
右：elevation/shadow/motion。
标题：**Flat 不是终点：数字材料重新回来，但承担的是结构语义。**

## Board E：GUI → AI
左：Folder / Trash / Desktop。
右：Avatar / Voice / “I” / typing indicator。
标题：**物的拟物 vs 主体的拟人。**

## Board F：今天的 AI → Agent-native UI
左：一个有头像的聊天助手。
右：Role / Principal / Scope / Permissions / Audit / Revoke 面板。
标题：**从“它像谁”到“它被谁授权、正在做什么、谁负责”。**
