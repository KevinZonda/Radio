# 历史界面图片镜头表与推荐图注


> **证据标签**
> - **[史实]**：有原始资料、官方文档或学术文献直接支撑。
> - **[解释]**：基于多条史实做出的分析性归纳，不等于当事设计团队的原话。
> - **[假说]**：可检验的理论延伸，尤其用于 AI-native UI 部分。
> - **[限制]**：与主叙事相冲突、限制其外推范围、或提醒避免后见之明的证据。


## 1. Xerox Star desktop / icons
**画面重点**：documents、folders、in/out baskets、printer 等。
**图注**：早期 GUI 的关键不只是“图标”，而是把文件系统翻译成办公室 ontology：用户操作熟悉的对象，而不是直接操作程序、路径和存储结构。

## 2. Apple Lisa Office System
**画面重点**：desktop、documents、folders、trash、menus。
**图注**：Lisa 的官方 UI 标准以 simplicity、integration 和 familiar concepts 为目标，把 consistency 当成降低学习成本的手段。

## 3. Macintosh 1984 / System 1
**画面重点**：menu bar、icons、windows、mouse pointer、MacPaint/MacWrite。
**图注**：黑白界面在视觉上并不“拟物”，但 semantic/behavioral skeuomorphism 极强：desktop、folder、trash、drag、WYSIWYG 组成一整套可迁移的 interaction grammar。

## 4. Windows 1.0
**画面重点**：tiled windows、MS-DOS Executive。
**图注**：早期 Windows 仍显著暴露 program-centric ontology；GUI 更像 DOS 世界上的视觉控制层。

## 5. Windows 3.1 Program Manager + File Manager
**画面重点**：两个不同管理器。
**图注**：用户需要同时理解“程序在哪里”与“文件在哪里”，说明今天看似自然的 app/file 区分曾经需要被明确教学。

## 6. Windows 95 Start Menu + Taskbar
**画面重点**：Start、running task entries。
**图注**：Windows 95 的 usability research 表明，新手的核心困难之一是系统状态不可见；Taskbar 的价值是让“仍然存在的任务”持续可见。

## 7. Windows XP Luna
**画面重点**：绿色 Start、蓝 taskbar、圆角/梯度、task pane。
**图注**：XP 强化 affordance 和 task orientation，使家用 PC 更像友好的消费设备。

## 8. Vista Aero / Windows 7 Aero
**画面重点**：glass、thumbnail、live preview、taskbar progress。
**图注**：Aero 的质感不只是现实仿真；在成熟桌面中，透明、preview、progress 更重要的作用是表达 context、state 与 task relationship。

## 9. iOS 6 Notes / Calendar / iBooks
**画面重点**：纸、皮革、木架等。
**图注**：在触屏交互尚未完全文化化的阶段，object metaphor、physical motion 与 direct manipulation 联合降低了新交互方式的 semantic distance。

## 10. Windows Phone Metro
**画面重点**：大 typography、Live Tiles、无传统 bevel、content-first。
**图注**：Metro 将“authentically digital”直接写入设计理念：内容优先、减少 chrome、避免无必要的 analog control 模拟。

## 11. iOS 7
**画面重点**：borderless control、translucency、layering。
**图注**：iOS 7 没有消灭所有物理性，而是减弱 object realism，同时用 layers 与 realistic motion 表达 depth。

## 12. Material Design elevation sheet
**画面重点**：paper/surface、shadow、z-axis、motion。
**图注**：Material Design 用纸张实验建立数字材料规则，代表“模仿具体物件”向“模拟材料规律”的转变。

## 13. Fluent Acrylic/Mica
**画面重点**：translucent surfaces、layer hierarchy。
**图注**：post-flat 中，材料更多承担 hierarchy、focus、context，而不是告诉用户“这是真的玻璃”。
