# 可检验的研究假说


> **证据标签**
> - **[史实]**：有原始资料、官方文档或学术文献直接支撑。
> - **[解释]**：基于多条史实做出的分析性归纳，不等于当事设计团队的原话。
> - **[假说]**：可检验的理论延伸，尤其用于 AI-native UI 部分。
> - **[限制]**：与主叙事相冲突、限制其外推范围、或提醒避免后见之明的证据。


## H1：社会拟物脚手架假说
初次使用 agentic system 的用户，在有 name/avatar/voice/personality 的条件下，会更快形成可操作 mental model，但也更可能高估 agent 的 intention continuity 或 responsibility。

## H2：内化后撤架假说
当用户对 delegation/permission/audit 等 primitives 熟练后，anthropomorphic cues 对 task success 的边际帮助下降。

## H3：角色界面优于人格界面（高风险任务）
在金融、采购、企业操作等高责任场景，role/authority/provenance UI 可能比 warm/personality UI 更能提高 appropriate reliance。

## H4：Face cue 会引入社会偏见
不同 avatar identity 在能力相同的条件下会改变 perceived expertise、trust 与 adoption；2026 AI tutor 研究已有相邻证据。

## H5：Institutional cues 能降低 anthropomorphic over-attribution
明确显示 principal、scope、memory、failure mode 与 responsibility owner，会降低用户把 agent 当作“拥有统一人格与无限能力的人”的倾向。

## H6：Agent-native literacy 可被社会化
像 drag/drop、pinch-to-zoom 一样，delegate/revoke/audit 可能最终从显式教学转为社会常识。

## 实验建议

- novice vs experienced agent users；
- face/personality UI vs role/credential UI vs hybrid；
- low-stakes vs high-stakes tasks；
- measure：task success、mental model accuracy、overtrust、appropriate reliance、error recovery、delegation calibration。
