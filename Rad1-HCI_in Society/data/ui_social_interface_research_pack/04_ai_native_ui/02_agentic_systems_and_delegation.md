Baird & Maruping 2021 的 MIS Quarterly 论文提出：传统 IS use 理论过度把 artifact 当被动工具；新一代 agentic artifacts 可以主动行动、接受任务，并在不确定环境中承担更大责任，因此需要用 **delegation** 重新理解 human–artifact relationship。
来源：https://aisel.aisnet.org/misq/vol45/iss1/12/

论文关注与 delegation 有关的 agent attributes（endowments、preferences、roles）以及 appraisal、distribution、coordination 等机制。

## 与 UI 历史的连接

传统 GUI primitives：

- select
- open
- drag
- drop
- undo

Agentic UI 可能需要新 primitives：

- delegate
- authorize
- constrain
- inspect
- verify
- approve
- pause
- revoke
- handoff
- audit

**[假说]** 这相当于从“操作对象”转向“治理行动者”。UI 的核心不再只是 affordance，而是 **agency legibility**。
