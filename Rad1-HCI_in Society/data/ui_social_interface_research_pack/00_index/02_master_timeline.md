# 总时间线：从可见对象到原生数字/代理属性


> **证据标签**
> - **[史实]**：有原始资料、官方文档或学术文献直接支撑。
> - **[解释]**：基于多条史实做出的分析性归纳，不等于当事设计团队的原话。
> - **[假说]**：可检验的理论延伸，尤其用于 AI-native UI 部分。
> - **[限制]**：与主叙事相冲突、限制其外推范围、或提醒避免后见之明的证据。


| 年代 | 系统/思想 | 当时解决的问题 | 可视为在“训练”什么 |
|---|---|---|---|
| 1960s–70s | CLI / timesharing | 精确控制机器 | 用户学机器 vocabulary 和 syntax |
| 1973+ | Xerox Alto | 图形显示、mouse、WYSIWYG | 图形对象可以直接操作 |
| 1981 | Xerox Star | 办公人员如何用工作站 | document/folder/printer 等办公室 mental model |
| 1980–83 | Apple Lisa | simplicity + integration | 一致 GUI、已知概念迁移、新手可学性 |
| 1984 | Macintosh | GUI 面向大众 | WIMP、菜单、直接操作、跨 app consistency |
| 1985 | Windows 1.0 | DOS 上的 GUI | 程序/窗口管理的视觉语法 |
| 1990–92 | Windows 3.x | GUI 生态规模化 | Program Manager / File Manager / dialogs / menu conventions |
| 1995 | Windows 95 | 新手找程序、管理最小化窗口、理解状态 | Start = home base；Taskbar = persistent task visibility |
| 2000 | Mac OS X Aqua | 下一代桌面 + delight | digital space、motion、Dock、透明层次 |
| 2001 | Windows XP Luna | 家庭消费化、task-based UI | 强 affordance、任务导向、友好反馈 |
| 2006 | Vista Aero | 高分辨率、GPU compositor、窗口状态 | glass / animation / thumbnails 作为 context 与状态线索 |
| 2007–12 | iPhone OS / iOS 1–6 | 普及 capacitive touch | tap/swipe/pinch + object metaphor + direct manipulation |
| 2009 | Windows 7 | 应用启动与任务切换碎片化 | app identity 合并 launch/switch/state |
| 2010–12 | Windows Phone / Metro | 小屏触控与信息密度 | typography、content-not-chrome、authentically digital |
| 2013 | iOS 7 | 视觉重构但保持熟悉交互 | physical realism muted；layers + realistic motion 表达 depth |
| 2014 | Material Design | 跨设备统一数字材料语言 | 从“模仿东西”到“模拟材料规则/层级/运动” |
| 2017+ | Fluent | 多设备、多输入、空间层次 | light/depth/motion/material/scale 表达关系 |
| 2020s | post-flat | 高 UI literacy 下重新增加质感 | materials 成为 hierarchy/focus/context 的编码 |
| 2020s– | conversational AI | AI 能力进入日常 | 用“人”的语言/人格理解非人智能 |
| 下一阶段？ | agent-native UI | 自主 agent、 delegation、governance | 权限、来源、责任、撤销、审计成为新 primitives |
