# 20 分钟演讲结构

## 0–2 min：一句话钩子
“为什么 1984 的黑白 Macintosh 其实比今天很多 3D UI 更拟物？”

## 2–5 min：重新定义拟物
semantic / behavioral / visual skeuomorphism。

## 5–8 min：Xerox → Lisa → Mac
从 command 到 object，从 recall 到 recognition，从 program 到 document。

## 8–11 min：Windows 95
展示 Beginner Shell、Start、Taskbar 的 usability evidence。

## 11–14 min：iOS 6 → Metro → iOS 7 → Material
“撤架”与“数字物理”。

## 14–16 min：社会同态
money / uniform / corporation / traffic / elevator operator。

## 16–18 min：AI 现在在哪里
avatar、voice、personality = social skeuomorphism？

## 18–20 min：未来 UI
delegate / authorize / inspect / verify / revoke / audit / handoff。

结尾句：
**GUI 的成熟让我们不再需要把数字对象伪装成现实物体；Agent UI 的成熟，也许会让我们不再需要把数字行动者伪装成一个人。**
