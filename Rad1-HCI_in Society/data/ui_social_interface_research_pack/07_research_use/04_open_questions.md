# 开放问题

1. “UI literacy”如何定量测量？是任务完成、错误率、眼动，还是 mental model accuracy？
2. 某个 convention 在多大普及率后，设计者可以安全撤去 signifier？
3. iOS 6 → iOS 7 的变化中，审美、品牌、技术与教育内化各自贡献多大？
4. 为什么 Windows 8 的某些 gesture 没能顺利“撤架”？设备 modality 是否比用户经验更重要？
5. anthropomorphic cues 何时增加 appropriate reliance，何时只增加 affective trust？
6. role/credential UI 会不会太官僚、降低亲和力？能否 hybrid：social layer + institutional layer？
7. agent 需要什么最小可见状态，才能像 Windows 95 Taskbar 那样避免“任务仍在运行但用户不知道”？
8. AI 的“Taskbar 等价物”是什么？一个全局 agent activity surface？
9. memory、tool use、external action 是否应成为统一可见 primitives？
10. 多 agent 系统里，用户应看到完整 delegation graph，还是只在异常时展开？
11. corporation 的 legal persona 与 AI agent 的 operational persona 到底有哪些关键不同？
12. “无脸化”是否会产生新的责任模糊？如何防止抽象系统把责任藏起来？
