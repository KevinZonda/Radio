## 交通

没有固定交通规则时，路口协调需要眼神、手势、地位判断与即时谈判。

交通灯、标志、车道与通行规则把它变成 protocol：陌生人不需要彼此了解，也可以高速协调。

**[解释]** 这是一种 face-based coordination → protocol-based coordination。

## 排队 / 取号

排队把“谁更有权先获得服务”的复杂社会竞争压成一个空间位置；取号机进一步把位置变成 token：A037。

```text
身份/魅力/关系/声音/冲突
            ↓
        queue position
            ↓
            A037
```

## 对 agent UI 的启发

成熟的 multi-agent interaction 不一定是两个“人格”互相聊天。它可以更像 protocol：

- request
- capability discovery
- authorization
- commit
- ack
- timeout
- revoke
- handoff

**[假说]** AI-native social UI 的终局可能更像交通规则或网络协议，而不是“更多拟人对话”。
