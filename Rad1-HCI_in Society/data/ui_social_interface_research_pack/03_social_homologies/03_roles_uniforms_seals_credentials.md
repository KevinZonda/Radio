# 制服、印章、签名、证书：把“认识人”变成“识别角色与授权”


> **证据标签**
> - **[史实]**：有原始资料、官方文档或学术文献直接支撑。
> - **[解释]**：基于多条史实做出的分析性归纳，不等于当事设计团队的原话。
> - **[假说]**：可检验的理论延伸，尤其用于 AI-native UI 部分。
> - **[限制]**：与主叙事相冲突、限制其外推范围、或提醒避免后见之明的证据。


## 制服

制服不是单纯服装，它是 **role visualization**：用户不需要知道工作人员的完整个人身份，就能迅速获得“这是谁、能做什么、在哪个机构体系里”的线索。

## 印章 / 签名 / 证书

这些机制解决 remote authority：主体不在场时，权威和承诺如何继续存在、如何被验证。

```text
face-to-face authority
        ↓
seal / signature / certificate
        ↓
verifiable credential
```

## 对 AI UI 的直接映射

今天：头像 + 人名 + personality。
未来可能是：

```text
Procurement Agent
Principal: ACME Inc.
Role: Purchasing
Authority: <= $25,000
Scope: office supplies
Valid until: 2026-09-30
Human approval required above: $5,000
```

**[假说]** 这相当于把 agent 从“character”重新设计成“institutionally situated role”。
