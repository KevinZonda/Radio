# 公司：社会已经接受“没有一张脸的持续主体”


> **证据标签**
> - **[史实]**：有原始资料、官方文档或学术文献直接支撑。
> - **[解释]**：基于多条史实做出的分析性归纳，不等于当事设计团队的原话。
> - **[假说]**：可检验的理论延伸，尤其用于 AI-native UI 部分。

公司不是某一个员工、CEO、股东或办公楼，但法律与社会可以把它当作连续主体：签约、持有资产、承担债务、起诉、被诉、长期存在。

Margaret Blair 2013 总结 corporate personhood 的功能，包括连续性、形成 identifiable persona、资产分隔与内部治理。
来源：https://scholarship.law.vanderbilt.edu/faculty-publications/18/

Elizabeth Pollman 2021 讨论 19 世纪美国 corporate form 的 legal personality 如何强化 corporation 与参与者相分离的实体特征。
来源：https://scholarship.law.vanderbilt.edu/vlr/vol74/iss6/5/

## 与 agent 的同态

```text
1000 humans + assets + procedures + contracts
                  ↓
             “Company X”
```

未来也可能出现：

```text
many humans + models + tools + policies + memory
                  ↓
               “Agent X”
```

**[解释]** corporation 提供了一个重要先例：社会主体不必等于一个身体。真正关键的是可识别性、持续性、权限、责任归属和治理结构。
